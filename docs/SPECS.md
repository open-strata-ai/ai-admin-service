## 1. API Contract

### 1.1 Transport & Conventions

| Aspect | Specification |
| --- | --- |
| Protocol | REST (Spring MVC + SpringDoc OpenAPI 3) |
| Base Prefix | `/api/v1/admin` |
| Consumer | `ai-admin-frontend` (platform-level endpoints require `platform-admin` role) |
| Auth Header | `Authorization: Bearer <JWT>` + `X-Tenant-Id` |
| OpenAPI | `openapi.yaml` auto-generated by SpringDoc; reuses `PlatformManifest` schema (§12.1) |

| Method | Path | Description | Auth Role |
| --- | --- | --- | --- |

### 1.3 HTTP Status Codes

| Code | Meaning |
| --- | --- |
| `2xx` | Success |
| `400` | Parameter / dependency validation violation |
| `401` | Unauthenticated |
| `403` | Unauthorized (non-platform-admin calling platform-level endpoint) |
| `404` | Resource not found |
| `409` | Quota conflict / whitelist conflict |
| `422` | Manifest dependency validation failure (§12.4) |
| `429` | Admin operation rate limit |
| `500` | Internal server error |


### 1.5 Business Error Codes

| Code | HTTP | Description |
| --- | --- | --- |
| `ENTITLEMENT_DEP_VIOLATION` | 422 | Component whitelist violates dependency graph |
| `TENANT_NOT_FOUND` | 404 | Tenant governance record not found |
| `QUOTA_CONFLICT` | 409 | Quota dimension already exists / conflict |
| `MODEL_RESTRICTED` | 403 | Model requires Enterprise plan |
| `PROVISIONING_IN_PROGRESS` | 409 | Another provisioning plan is active for this tenant |

## 2. Data Model

### 2.1 Database

| Attribute | Value |
| --- | --- |
| Engine | PostgreSQL 16.0 (core, §16 base) |
| Schema | `admin_gov` (shared) |
| Multi-tenant isolation | `tenant_id` column + RLS (§8.2) |
| ORM | JPA (Hibernate 6 / Jakarta Persistence) |
| Migration | Flyway (`V1__admin_init.sql`) |
| Note | **Does NOT hold authoritative business data** (in `ai-platform-api`). Only governance orchestration state + audit. |

### 2.2 Table DDL

```sql
-- Tenant Governance (orchestration state)
CREATE TABLE tenant_governance (
  tenant_id        VARCHAR(64) PRIMARY KEY,
  package          VARCHAR(32) NOT NULL,        -- Trial/Standard/Enterprise
  quota_policy     JSONB       NOT NULL,         -- CPU/Mem/GPU/Token/QPS/Vector
  entitlements     JSONB       NOT NULL,         -- component whitelist
  model_whitelist  JSONB       NOT NULL,
  isolation_spec   JSONB,                        -- Namespace/NP/Queue/Prefix/Bucket
  updated_at       TIMESTAMPTZ NOT NULL DEFAULT now()
);

-- Provisioning Plans (orchestration tracking)
CREATE TABLE provisioning_plans (
  plan_id     VARCHAR(64) PRIMARY KEY,
  tenant_id   VARCHAR(64) NOT NULL,
  manifest    JSONB       NOT NULL,             -- tenant PlatformManifest.spec
  status      VARCHAR(16) NOT NULL DEFAULT 'PENDING',  -- PENDING/APPLYING/DONE/FAILED
  created_at  TIMESTAMPTZ NOT NULL DEFAULT now()
);

-- Audit Log (immutable, INSERT-ONLY)
CREATE TABLE audit_log (
  id          BIGSERIAL PRIMARY KEY,
  actor       VARCHAR(64) NOT NULL,
  scope       VARCHAR(8)  NOT NULL,             -- platform / tenant
  tenant_id   VARCHAR(64),
  action      VARCHAR(64) NOT NULL,
  payload     JSONB,
  created_at  TIMESTAMPTZ NOT NULL DEFAULT now()
);
CREATE INDEX idx_audit_tenant ON audit_log(tenant_id, created_at);
```

### 2.3 JPA Entity Mapping

| Entity | Table | JSONB Columns | Notes |
| --- | --- | --- | --- |
| `TenantGovernanceEntity` | `tenant_governance` | `quota_policy`, `entitlements`, `model_whitelist`, `isolation_spec` | Mirror of platform-api state |
| `ProvisioningPlanEntity` | `provisioning_plans` | `manifest` | Tracks orchestration lifecycle |
| `AuditEntryEntity` | `audit_log` | `payload` | INSERT-ONLY, immutable |

### 2.4 Value Object Column Types

| Domain VO | DB Column | Type |
| --- | --- | --- |
| `PackageAssignment` | `tenant_governance.package` | `VARCHAR(32)`, enum: Trial/Standard/Enterprise |
| `ProvisioningStatus` | `provisioning_plans.status` | `VARCHAR(16)`, enum: PENDING/APPLYING/DONE/FAILED |
| `AuditScope` | `audit_log.scope` | `VARCHAR(8)`, enum: platform/tenant |
| `ResourceQuota` | `tenant_governance.quota_policy` | `JSONB` |

## 3. Configuration

### 3.1 Service Configuration

```yaml
openstrata:
  service:
    port: 8088
  features:
    admin:
      enabled: true                 # core, all four profiles
    gpuPool:
      enabled: false                # only full profile (self-hosted inference)
    multiTenant:
      enabled: false                # starter/standard=false; advanced/full=true
    billingView:
      enabled: false                # only multi-tenant (advanced/full)
    modelRegistry:
      enabled: true
  spi:
    auth:        { provider: keycloak }   # core
    multitenancy:{ provider: capsule }    # optional, multi-tenant only
    cache:       { provider: redis }      # valkey alternative
```

### 3.2 Profile → Governance Dimension Matrix

| Profile | admin | gpuPool | multiTenant | billingView | Capsule | Kueue |
| --- | --- | --- | --- | --- | --- | --- |
| starter | true | false | false | false | — | — |
| standard | true | false | false | false | — | — |
| advanced | true | false | true | true | injected | — |
| full | true | true | true | true | injected | injected |

### 3.3 Configuration Keys Reference

| Key | Type | Default | Profiles | Description |
| --- | --- | --- | --- | --- |
| `openstrata.service.port` | int | `8088` | all | HTTP listen port |
| `openstrata.features.admin.enabled` | bool | `true` | all | Enable admin service (always on) |
| `openstrata.features.gpuPool.enabled` | bool | `false` | full | Enable GPU pool governance (Kueue) |
| `openstrata.features.multiTenant.enabled` | bool | `false` | advanced/full | Enable multi-tenancy governance |
| `openstrata.features.billingView.enabled` | bool | `false` | advanced/full | Enable billing cost view |
| `openstrata.features.modelRegistry.enabled` | bool | `true` | all | Enable model registry integration |
| `openstrata.spi.auth.provider` | string | `keycloak` | all | Auth SPI provider |
| `openstrata.spi.multitenancy.provider` | string | `capsule` | advanced/full | Multi-tenancy SPI provider |
| `openstrata.spi.cache.provider` | string | `redis` | all | Cache SPI provider |

### 3.4 Externalized Configuration

| Source | Description |
| --- | --- |
| ConfigMap | Service settings (port, feature flags, SPI providers) |
| Secret | DB credentials, Keycloak client secrets |
| Helm values | Rendered by `ai-provisioning-engine` (§13.3); constrained by `multiTenant`/`billingView` dependency chain |
| Governance dimensions | Expand with profile; Capsule Adapter injected conditionally |
| Readiness probes | Depends on PostgreSQL, Redis, Keycloak, and `ai-platform-api` |
